# Autoevaluación GRD

Lista de autoevaluación de aspectos legales asociados a la Gestión del Riesgo de Desastres (GRD) en centros de trabajo, como herramienta web de una sola página.

Estándar, aplicable a cualquier empresa. Sin backend: los datos se guardan solo en el navegador.

**En línea:** https://maah1996.github.io/autoevaluacion-grd/

Fuente del contenido: Lista de Autoevaluación de Aspectos Legales GRD — Dirección del Trabajo · SUSESO · SENAPRED · organismos administradores Ley N°16.744 (56 preguntas).
